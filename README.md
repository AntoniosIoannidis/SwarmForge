# ⚡ SwarmForge AI

### *Autonomous Drag-and-Drop Visual AI Agent Swarm Creator & Orchestrator*

SwarmForge is a state-of-the-art, zero-dependency, in-browser visual workspace designed to let you **visually design, connect, configure, and execute autonomous multi-agent AI pipelines** in real-time. 

With a premium glassmorphic dark mode UI, smooth pannable grid workspace, and dynamic SVG vector cables, SwarmForge brings visual flow engineering to autonomous multi-agent systems.

---

## 🚀 Key Features

- 🎨 **Visual Drag-and-Drop Canvas:** An interactive, pannable grid workspace where you can click or drag specialized agent nodes, wire their input/output handles, and organize complex workflows.
- 📐 **Dynamic Vector Connections:** Connected ports calculate dynamic Bezier curves in an SVG overlay, updating fluidly as you move nodes.
- 📋 **Topological Execution Scheduler:** Traces the cable configurations, resolves dependencies, and schedules execution sequence pipelines automatically.
- 📟 **Real-time Swarm Console & Debater:** A scrolling terminal displaying typewriter logs of agents collaborating, arguing, and reaching consensus.
- 📦 **Generated File Vault:** As the swarm runs, it produces code modules, stylesheets, reports, and scripts (e.g. index.html, python scripts, consensus dossiers) saved directly in an in-browser preview tab.
- 🔌 **Dual Execution Modes:**
  - **Real API Mode:** Paste your Google Gemini API key to run real-time asynchronous multi-agent swarms using `gemini-2.0-flash`.
  - **Mock Sandbox Mode:** Run a highly immersive quantitative stock/crypto or software engineering board debate without an API key.
- 💾 **JSON Configurations:** Import and export your visual swarm canvas configuration as single-file `.json` modules to share with the community.

## 🏁 Quickstart Guide

### 1. Launch SwarmForge Locally
Since SwarmForge is a pure front-end web app, you can launch it in seconds using any lightweight web server:

```bash
# Using Node's npx
npx http-server -p 8080
```

Now, navigate your browser to **`http://localhost:8080`**.

### 2. Load a Preset Collective
Click the **Swarm Presets** dropdown at the top to instantly load and auto-wire structured teams:
- **Software Engineering Team:** (Planner ➔ Researcher ➔ Coder ➔ Designer ➔ Auditor) to write a functional Todo Kanban app.
- **Hedge Fund Quantitative Board:** (Director ➔ Data Analyst ➔ Python Engineer + Sentiment Evaluator ➔ Board Auditor) to calculate trade consensus signals for NVDA and TSLA.

### 3. Run the Swarm Pipeline
Click **⚡ Run Swarm Pipeline** to watch the scheduler activate incoming visual pathways, launch nodes in sequence, stream agent debates, and store generated files in the **Generated Vault**.

## 💻 Tech Stack & Design Architecture

Built from the ground up to follow strict **UI/UX Mastery** and **Scalable Software Architecture** playbooks:

- **Core Logic:** Pure ES6 Javascript utilizing a decoupled state-controller model.
- **Visual Presentation:** Semantic HTML5 and custom HSL-powered Vanilla CSS, backing a dot-pattern workspace matrix.
- **Animations:** High-performance, hardware-accelerated CSS transforms and keyframe glows.
- **Connections:** Dynamic SVG vector graphics calculating curved path nodes.
- **Integration:** Standard fetch API interfacing with Google Gemini REST endpoints.
